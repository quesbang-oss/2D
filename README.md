# 柿込2D Animation Studio

GitHub Pagesでそのまま公開できる2D専用アニメーション制作ソフトです。

## GitHub Pagesへの公開

1. このフォルダの `index.html` と `README.md` をGitHubリポジトリのルートへアップロード
2. GitHubの **Settings → Pages** を開く
3. **Deploy from a branch** を選択
4. Branchを `main`、Folderを `/ (root)` にして保存
5. 表示されたURLを開く

## 保存・バックアップ

- **ファイル → プロジェクトを保存**：`.k2d.json` として手元に保存
- **ファイル → プロジェクトを開く**：保存した `.k2d.json` を復元
- **自動保存**：IndexedDBへ自動保存。初期設定は60秒ごと
- 編集後は約3秒の遅延自動保存も行います
- ページを別タブへ移す・閉じる直前にも自動保存を試みます
- 自動保存はブラウザ内に保持され、最大5件のバックアップ履歴を残します
- **ファイル → 自動保存から復元** から自動保存・バックアップを選んで復元できます

### 注意

ブラウザのサイトデータ削除、シークレット/プライベートブラウジングの終了、別ブラウザ・別PCへの移行ではブラウザ内バックアップを引き継げない場合があります。重要な作品は `.k2d.json` として定期的に手元にも保存してください。
