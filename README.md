柿込2D Animation Studio — セットアップ手順
====================================================

このフォルダには、ソフト本体（柿込2D.html）と、
お使いのパソコンに合わせたデスクトップショートカット作成スクリプトが
入っています。インストール作業は不要です。すべてブラウザ上で動作します。


【まずやること】
1. このフォルダをまるごと、お好きな場所（デスクトップやドキュメント等）に置いてください。
   ※ フォルダの中身を移動・分割すると、ショートカットが動かなくなります。
2. お使いのOSに合ったスクリプトをダブルクリックしてください。

   Windows の方 → 「Windows_デスクトップにショートカット作成.vbs」
   Mac の方     → 「Mac_デスクトップにショートカット作成.command」
   Linux の方   → 「Linux_デスクトップにショートカット作成.sh」

3. デスクトップに「柿込2D Animation Studio」のアイコンが作成されます。
   以降は、そのアイコンをダブルクリックするだけでソフトが起動します
   （お使いのブラウザが自動的に開きます）。

ショートカットを作らず、直接使いたい場合は「柿込2D.html」を
そのままダブルクリックしてもソフトが起動します。


【対応ブラウザ】
Google Chrome / Microsoft Edge の最新版を推奨します。
Firefox・Safariでも動作しますが、書き出し機能の一部（動画形式）は
ブラウザによって対応状況が異なります。


【Windows をお使いの方への注意】
初回実行時に「WindowsによってPCが保護されました」という青い画面が
表示される場合があります。これはインターネット経由で取得した
スクリプトに対する標準の警告です。
内容に問題がないことを確認のうえ、
「詳細情報」→「実行」の順にクリックしてください。


【Mac をお使いの方への注意】
初回実行時に「開発元を確認できないため開けません」と表示される
場合があります。その場合は、
1. Finderでファイルを右クリック（Controlキーを押しながらクリック）
2. メニューから「開く」を選択
3. 表示されるダイアログで再度「開く」を選択
としてください。一度許可すれば、次回からは通常どおりダブルクリックで
実行できます。


【Linux をお使いの方への注意】
デスクトップ環境（GNOME等）によっては、作成されたアイコンを
右クリックし「実行を許可する（Allow Launching）」を選ぶまで
起動しない場合があります。


【データの保存について】
・作った作品はソフト内の「ファイル→プロジェクトを保存」で
  お使いのパソコンに保存できます（.k2d.json ファイル）。
・作業中は自動保存が働き、ブラウザを閉じてしまった場合も
  次回起動時に「前回の作業データが見つかりました」と表示されれば
  復元できます。
・すべてのデータはお使いのブラウザ内で処理され、外部には送信されません。


【使い方が分からないときは】
ソフト内のメニュー「ヘルプ→使い方」に、基本操作の手順をまとめています。
